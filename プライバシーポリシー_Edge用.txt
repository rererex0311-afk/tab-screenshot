全タブ一括スクリーンショット　プライバシーポリシー
============================================
（公開する前に、【】の部分を書き換えてください）

本ポリシーは、Microsoft Edge 用の拡張機能「全タブ一括スクリーンショット」（以下「本拡張機能」）における
利用者の情報の取り扱いについて定めるものです。

提供者：【中野 智仁】
お問い合わせ：【rererex0311@gmail.com】
制定日：【2026年11月1日】

1. 取り扱う情報
本拡張機能は、ページを撮影するために、次の情報を利用者の Microsoft Edge の中で扱います。
・開いているタブのタイトルとURL
・撮影するページの表示内容
・枠（iframe）の中で表示している画面のURL（タブの一覧を保存する場合）
・利用者が入力した保存名、物件名・点検者・メモ、除外キーワードなどの設定
・サイトごとの設定・物件名を使う場合、そのサイトのアドレスのホスト名（例：192.168.1.10）と、覚えさせた物件名
・自動撮影を使う場合、その登録（撮影する時刻・間隔と、撮影するタブの選び方または保存したタブ一覧。今開いているタブを撮る登録では、登録したウィンドウのタブのサイトのホスト名）

2. 利用目的
上記の情報は、利用者が操作したときに、撮影するタブを選ぶ・ページを撮影する・撮影した画像に
撮影日時やアドレス、利用者が入力した物件名・点検者・メモを記録する・タブの一覧を保存して開き直す、という本拡張機能の機能のためだけに使います。

3. 保存場所
・撮影した画像・PDF・Excel のファイル・撮影一覧（CSV）は、利用者のパソコンの「ダウンロード」フォルダに保存されます。
・設定、保存したタブの一覧、保存名の履歴、直前の撮影結果は、利用者の Microsoft Edge の中
  （拡張機能のデータ）にだけ保存されます。
・「撮影した分を一時保存して、あとで1つのPDFに」を使う場合、PDFにするまでの間、撮影した画像をブラウザーの中
  （拡張機能のデータ）に一時保存しておきます。PDFにすると消去されます。
・「画像をコピー」のため、直前の撮影で最後に撮影した画像を1枚だけブラウザーの中（拡張機能のデータ）に残します。
  次の撮影で入れ替わります。クリップボードへは、利用者がコピーのボタンをクリックしたときだけ写します。
・「最近の撮影」のため、最近の10回分の撮影について、結果（ページ名・撮影日時・保存したファイルの名前）と
  小さな画像、最後に撮影した画像をブラウザーの中（拡張機能のデータ）に残します。11回目からは古いものを削除します。
  同じ画面の「最近の撮影」で、いつでも削除できます。

4. 外部への送信・第三者への提供
本拡張機能は、上記の情報を含むいかなるデータも、提供者を含む外部へ送信しません。
アクセス解析、広告、利用状況の収集も行いません。提供者は利用者の情報を取得しないため、
第三者へ提供・販売することもありません。

5. 利用者による確認・削除の方法
・設定：本拡張機能のアイコンをクリックして開く画面で確認・変更できます。「初期設定に戻す」で最初の状態に戻せます。
・サイトごとの設定：同じ画面の「このサイトの設定」で確認・削除できます（「初期設定に戻す」では消えません）。
・サイトごとの物件名：同じ画面の「物件名・点検者・メモ」で確認・削除できます。
・自動撮影の登録：同じ画面の「自動撮影」で確認・停止・削除できます。
・保存したタブの一覧：同じ画面の「タブの保存」で確認・削除・書き出しができます。
・撮影した画像などのファイル：「ダウンロード」フォルダの中で、通常のファイルと同じように確認・削除できます。
・PDF用に一時保存した画像：アイコンの画面の「一時保存した画像を削除する」で、いつでも消去できます。
・本拡張機能を Microsoft Edge から削除すると、Microsoft Edge の中に保存した設定・タブの一覧などはすべて消去されます。

6. 権限について
本拡張機能は、スクロールしないと見えない部分まで撮影するために Microsoft Edge のデバッガー機能を使います。
デバッガー機能は、利用者が撮影を始めたときに、撮影するタブにだけ一時的に接続し、撮影が終わると切断します。
各ページに表示する撮影ボタンは、ボタンを表示するためだけのもので、ページの内容や入力内容を読み取りません。
保存するファイルを準備するために、画面に表示しない文書（offscreen）を保存の間だけ使います。ページの内容は読み取らず、外部へも送信しません。
自動撮影のために Microsoft Edge のアラーム機能を使います。利用者が登録した時刻に撮影を始めるためだけに使います。

7. 改定
本ポリシーを変更する場合は、このページで公開します。
